# Lecturers' dashboard - HTML intro homework

Static website (no build step) where lecturers see the students' quiz results: pick your name, enter the access code, choose a group.

- `index.html` - the dashboard (all code is inside this one file)
- `config.js` - the address of the results API
- Needs the **lecturer access code** to show any data. The code is never stored in this repository.

The API and the student quiz live in the main project: https://github.com/thothcher/html-intro-homework

## Update

Edit the file, then `git add -A && git commit -m "..." && git push`. GitHub Pages republishes in about a minute.

If the API address ever changes, edit `config.js`.
